# Event-specified Variables

Skript expression for reading and changing variables in a specified event context.

## Installation

Install with [Pacskage](https://github.com/miberrs/pacskage):

`package install https://github.com/devdinc/event-specified-variables`

Requires Skript 2.15+ and skript-reflect 2.6+.

## Source and tests

- Implementation: `src/event-specified-variables.sk`
- Tests: `-tests/event-specified-variables.test.sk`

Part of the [devdinc Skripts collection](https://github.com/devdinc/skripts).
